利用規約

制定日：［リリース日を記入］

本規約は、菅沼 展（以下「当方」）が提供するアプリ「栞 - AIノベル」（以下「本アプリ」）の利用条件を定めるものです。本アプリをご利用いただく方は、本規約に同意したものとみなします。

第1条（適用）

  1. 本規約は、本アプリの利用に関する当方と利用者との間の一切の関係に適用されます。
  2. 当方が本アプリ内に掲示する個別の案内やガイドラインは、本規約の一部を構成します。

第2条（利用資格）

  1. 本アプリは16歳以上の方を対象としています。
  2. 未成年の方は、親権者の同意を得たうえでご利用ください。
  3. 過去に本規約への違反により利用を停止された方は、ご利用いただけません。

第3条（AIによる生成物）

  1. 本アプリの文章および画像は、外部のAIによって自動生成されるものです。
  2. 生成される内容は架空のものであり、事実の正確性、有用性、特定の目的への適合性を当方は保証しません。
  3. 生成された内容は、実在の人物、団体、事件とは関係がありません。
  4. 同じ入力に対して常に同じ結果が生成されるとは限りません。また、生成が失敗する場合があります。
  5. 本アプリは、応答を生成するため、利用者の入力内容および会話履歴を、Google LLC（アメリカ合衆国）およびZ.ai（中華人民共和国）へ送信します。これらの事業者における取り扱いは、各社の定めるところによります。詳細はプライバシーポリシーをご確認ください。

第4条（禁止事項）

本アプリの利用にあたり、次の行為を禁止します。

  1. 法令または公序良俗に違反する行為
  2. 犯罪行為に関連する行為
  3. 他の利用者、第三者または当方の権利を侵害する行為
  4. 本アプリの運営を妨害する行為、または不正な手段により本アプリの制限を回避する行為
  5. 本アプリを、当方が想定しない方法で自動的に操作する行為
  6. 本アプリを通じて、他の利用者に対し外部の連絡先へ誘導する行為
  7. 実在する人物になりすまし、または実在する人物を誹謗中傷する内容を公開する行為
  8. その他、当方が不適切と判断する行為

第5条（作品の公開および共有）

  1. 利用者が作成した作品は、既定では非公開です。利用者が「公開」に設定した場合に限り、他の利用者が閲覧できる状態になります。
  2. 公開された作品には、題名、あらすじ、登場人物の設定、カバー画像が含まれます。会話の本文は公開されません。
  3. 公開作品には通報の機能が設けられており、通報を受けた作品を当方が確認する場合があります。
  4. 公開する作品には、次の内容を含めることができません。
    • 性的な描写
    • 実在する人物を特定できる情報
    • 外部の連絡先、URL、その他アプリ外への誘導
    • 第三者の権利を侵害する内容
  5. 本アプリの共有機能を用いて外部に投稿する内容についても、前項の制限が適用されます。
  6. 前二項に違反する作品について、当方は、事前の通知なく公開の停止または削除を行うことがあります。

第6条（権利の帰属）

  1. 本アプリおよび本アプリに含まれるプログラム、デザイン、素材に関する権利は、当方または正当な権利者に帰属します。
  2. 利用者が作成した作品の設定および生成された文章について、当方は権利を主張しません。
  3. ただし、AIによる生成物に著作権が発生するか否かは、生成過程における利用者の創作的関与の程度に応じて判断されます。当方は、生成物について利用者に著作権が発生することを保証するものではありません。
  4. 公開された作品について、当方は、本アプリ内での表示および本アプリの紹介に必要な範囲でこれを利用できるものとします。

第7条（しおり）

  1. 「しおり」は、本アプリ内でのみ利用できる前払式支払手段です。
  2. しおりは、記憶レベルの拡張、画像の生成、章の進行、エンディングの生成その他本アプリ内の機能に使用できます。
  3. しおりの有効期限は、購入日から180日間です。有効期限を過ぎた未使用のしおりは失効します。
  4. しおりの払い戻しは、資金決済に関する法律に定める場合を除き、行いません。
  5. しおりを他の利用者に譲渡し、または換金することはできません。
  6. 端末の変更、初期化または本アプリの削除により、残高が引き継がれない場合があります。この場合、購入履歴からの復元をお試しください。

しおりに関する法定の表示事項は、資金決済法に基づく表示をご確認ください。

第8条（有料サービス）

  1. 本アプリには、有料の月額プラン（チャットプラン）およびしおりの購入があります。
  2. お支払いは、Apple ID に登録されたお支払い方法によります。
  3. 月額プランは、解約の手続きを行わない限り自動的に更新されます。解約は App Store の設定から行えます。
  4. 購入手続きの完了後の返品およびキャンセルはお受けできません。返金に関するお問い合わせは、Apple のサポートへお願いいたします。

販売条件の詳細は、特定商取引法に基づく表記をご確認ください。

第9条（サービスの変更・中断・終了）

  1. 当方は、事前の通知なく、本アプリの内容を変更し、または提供を中断することがあります。
  2. 本アプリの提供を終了する場合は、原則として3か月前までに本アプリ内でお知らせします。
  3. 提供を終了する場合、未使用のしおりについては、法令に従い、当方の定める方法により払い戻しの手続きを行います。

第10条（免責）

  1. 当方は、本アプリが利用者の特定の目的に適合すること、期待する機能や価値を有すること、および不具合が生じないことを保証しません。
  2. 端末に保存されたデータの消失について、当方に故意または重大な過失がある場合を除き、当方は責任を負いません。
  3. 本アプリに関して当方が負う損害賠償の責任は、当方に故意または重大な過失がある場合を除き、利用者が過去1年間に本アプリに対して支払った金額を上限とします。
  4. AI事業者の障害、仕様の変更またはサービスの終了により本アプリの機能が制限された場合について、当方に故意または重大な過失がある場合を除き、当方は責任を負いません。

第11条（利用の停止）

利用者が本規約に違反した場合、当方は、事前の通知なく、公開作品の削除または本アプリの利用の停止を行うことがあります。

第12条（本規約の変更）

  1. 当方は、必要と判断した場合、本規約を変更することがあります。
  2. 利用者に不利益となる変更を行う場合は、本アプリ内で事前にお知らせしたうえで、改めて同意をいただきます。

第13条（準拠法および管轄）

  1. 本規約は、日本法に準拠して解釈されます。
  2. 本アプリに関して紛争が生じた場合、東京地方裁判所を第一審の専属的合意管轄裁判所とします。
